# Result

The loop round-tripped a `search_writing` tool call through LocalAI's
configured chat model (`spark-x2.6-4b-q4` here), executed hybrid retrieval, and produced an answer whose
claims named two retrieved `chunk_id`s. The finalizer resolved both to their
`source_url`s from the index and marked the answer grounded.

The off-corpus question took two tool iterations — the model searched twice,
found nothing that answered it, and returned the exact refusal string. No
citations were emitted (`citations: []`), proving the refusal path does not
invent sources.

`POST /v1/ask` returned the same `answer`/`citations`/`tool_iterations`/
`refused`/`elapsed_ms` struct as `agent ask`. The first HTTP attempt at
"What does Eli say about harnesses?" happened to refuse while the CLI with the
same wording answered; an immediate retry answered with three citations. That
is model non-determinism on a 4B model, not a surface difference — the CLI and
HTTP handler share the loop struct and are covered by a parity test.

Timing: 17.7s for a cited answer, 9.4s for the refusal, 17.6s over HTTP. All
are inside the Phase 2 CPU-host ceiling of 60s, and both budgets (3 tool
iterations / 4,000 excerpt tokens / wall clock) held.
