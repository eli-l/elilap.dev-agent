# Result

`agent backup` is the Phase 3 operator snapshot, implemented as an online
`VACUUM INTO` from a read-only handle:

```bash
./agent backup                         # index-<UTC stamp>.db next to the index
./agent backup --out /data/backup.db    # explicit destination; must not exist
```

- **Live-safe**: the source is opened with `store.OpenReadOnly`, so the
  command never creates or migrates the index, and another process may be
  writing while the snapshot runs.
- **Self-contained**: the output is a single database file with no
  `-wal`/`-shm` siblings. `agent stats` on the snapshot agrees with the source
  (949 chunks, FTS rows, and vectors; 3 sources).
- **Non-destructive**: an existing destination, a directory, or an empty path
  is refused before SQLite runs, so a typo cannot overwrite a previous
  snapshot. The default name carries a UTC stamp and sits next to
  `AGENT_DB_PATH` (i.e. `/data` in container mode).
- **Tested**: the store tests cover a read-only source handle, nested parent
  directory creation, an existing destination, and directory/empty-path
  rejection; the CLI tests cover the default name, a missing index leaving no
  file, an existing destination staying untouched, and an extra argument
  returning usage status.

The same pass fixed `scripts/ingest-all.sh`: it now `cd`s to the repository
root and executes the built `./agent ingest "$@"` instead of the removed
`go run ./cmd/ingest`, and exits with a build hint when `./agent` is missing.
`./scripts/ingest-all.sh --help` was used to verify the wrapper without a
network run.

Snapshots match `*.db` in `.gitignore`, so the file produced here stays out of
the repository.
