## 2026-11-13

* **Update**: The answer is now the summary alone, with the evidence attached by the service. The grounded prompt forbids citation markers, chunk ids, and a model-written source list, and the `search_writing` tool payload no longer carries `chunk_id`, so the identifier never enters the model's context. Every answer surface returns `answer` + `citations` (one per grounded excerpt, with `excerpt` text) + `sources` (one per distinct document), both always arrays and `[]` on a refusal. Chunk ids are logged on the debug `rag: answer` line and in the retrieval trace and are never returned. * **Creation**: A website is now a source. Politeness is built in: `defaults.user_agent`, a 250 ms delay, an 8 MiB response cap, and `/robots.txt` (longest-match Allow/Disallow) obeyed by default; a page marked `noindex` or one with no extractable text records a ledger row and writes no chunks. * **Creation**: `agent sources inspect` is the deterministic half of "let an LLM pick the parser". It fetches one page with a source's real options and reports status/metadata/JSON-LD/headings, every plausible content region with a stable CSS selector (`main > section:nth-of-type(3) > article`, ids where present, no utility classes), text volume, link density, and heading count, the discovery counts per source, and a suggested `strategy` + `selectors.content` with a one-line reason. Candidates are ranked by text discounted by link density with a bonus for `<article>`, and ancestors that repeat a descendant's text collapse to the deepest node. The output is text for a human or `--format json` for a model; ingest itself never calls a model. `Adapter` (`Name`/`Match`/`Select` returning a content node plus overrides) is the Go seam for sites no selector can express; `adapter_elilap.go` is the reference.
